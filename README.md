# Nourish

A food picker that helps you answer the daily question: **What should I eat?**

## Where the code lives

- `public/food-picker.html` is the whole app: markup, styles, and script in one file.
- `next.config.mjs` rewrites the home route (`/`) to the food picker, so it is the first page you see.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

Built with [v0](https://v0.app).
